# Salesforce — Agentic Maturity Model (4 Levels)

**Source:** https://www.salesforce.com/news/stories/agentic-maturity-model/

## Level 0: Fixed Rules / Chatbots
- Automation of repetitive tasks with predefined rules
- No reasoning or learning capabilities
- **Example:** FAQ bots, password reset, decision trees
- **Advance to Level 1:** Identify use cases where reasoning would improve outcomes; conduct time studies; ensure data quality

## Level 1: Information Retrieval Agents
- Assists humans by retrieving info and recommending actions
- **Example:** Agent pulls from knowledge base to suggest next steps for support ticket
- **Advance to Level 2:** Shift from recommendations to actions; harmonize data; establish broader governance; measure ROI (time savings, case deflection, CSAT)

## Level 2: Simple Orchestration (Single Domain)
- Autonomous orchestration of low-complexity tasks in siloed data environment
- **Example:** Auto-schedule meetings + follow-up emails from calendar/email
- **Advance to Level 3:** Decide mega-agent vs specialized agents; grant least-privilege access; design for future complexity; use API connectors

## Level 3: Complex Orchestration (Multiple Domains)
- Autonomous orchestration across multiple workflows with harmonized data
- **Example:** Sales pipeline + customer service + financial reports → holistic customer view
- **Advance to Level 4:** Real-time cross-domain collaboration; universal agent communication layer; dynamic agent discovery; fine-grained access control; layered human/AI supervision

## Level 4: Multi-Agent Orchestration
- Any-to-any agent operability across disparate stacks with agent supervision
- **Example:** Multiple agents processing orders, managing inventory, routing feedback across departments
- **Maximize value:** Evolve security for ecosystem collaboration; explore new business models; quantify multi-agent system value

## Critical Non-Technology Considerations
- Data readiness and integration
- Security and governance frameworks
- Workforce upskilling for human-agent collaboration
- Risk tolerance alignment per use case
