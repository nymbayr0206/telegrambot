# Hermes Visual Agent System Brief

## Зорилго

Hermes төсөл дээр визуал агентууд, skill, процесс, хийсэн ажлын бүртгэл, QA шалгалтыг нэг стандарт урсгалд оруулах.

## Хэрэглэгч

- Hermes dashboard хөгжүүлэгч
- UI/UX шалгагч
- Агент workflow зохион байгуулагч
- Төслийн явц хянагч

## Хүргэх үр дүн

- Монгол хэлтэй `/visual-agents` dashboard page
- Visual agent workflow баримт
- Work log, decisions, visual QA template
- Reusable Hermes visual agent skill

## UI зарчим

- Dashboard маягийн нягт, ажлын хэрэгсэлд тохирсон layout
- Монгол хэл дээр уншигдахуйц товч copy
- Desktop болон mobile дээр текст давхцахгүй байх
- Картуудыг давтагдах мэдээлэлд ашиглах
