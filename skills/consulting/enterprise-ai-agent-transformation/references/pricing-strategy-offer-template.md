# AI Transformation Service — Pricing Strategy & Offer Template

## Purpose

When a client wants pricing for AI agent transformation services, use this template to structure the offer. Built for the Mongolian market (AI Global) but adaptable to any market.

## Core Pricing Strategy

**Front-loaded affordable + per-skill/per-agent scaling**

The psychology: show a low entry price so the client thinks "that's affordable." The base includes 1-2 agents with basic skills. As their needs grow (more agents, more skills per agent), per-unit pricing kicks in automatically.

### Why This Works (Mongolia Market)
- Companies are skeptical of large upfront investments in unproven AI
- A freemium readiness assessment builds trust before any payment
- Per-skill/per-agent pricing mirrors how SaaS scales — familiar mental model
- The client sees a path: "start small, expand when we see ROI"

## The 4-Level Offer Structure

### 🆓 Freemium — AI Readiness Accelerator ($0)
**Purpose:** Lead generation, trust building, value demonstration

| Component | Description |
|-----------|-------------|
| Readiness Assessment | 6-dimension scoring workshop (2 hrs online). Maturity stage identification. |
| Time-Savings Calculator | Custom tool: inputs = headcount, manual tasks, frequency, avg salary. Outputs = hours/year saved, MNT/year saved. |
| AI Awareness Workshop | 3 hrs bilingual. Mongolia-specific case studies. Live agent demo. |
| Executive Summary | Roadmap recommendation + rough cost estimate. No obligations. |

**Key pitch:** "Let us show you your numbers before you spend a single tugrik."

## Dynamic Pricing Formula

```
Base Price = Platform Setup Fee
           + (Agent Count × Agent Price)
           + (Skill Count × Skill Price)
           × Integration Complexity Modifier
```

| Parameter | Starter | Growth | Enterprise |
|-----------|---------|--------|------------|
| Platform Setup | $1,500 | $4,000 | $10,000 |
| Per Agent | $1,500 | $1,200 | $1,000 |
| Per Skill | $500 | $400 | $300 |
| Complexity | ×1.0 | ×1.0–1.3 | ×1.2–1.8 |

### Worked Example
4 agents × 6 skills each = 24 skills total
- **Starter:** $1,500 + (4×$1,500) + (24×$500) = **$19,500**
- **Growth:** $4,000 + (4×$1,200) + (24×$400) = **$18,400**
- **Enterprise:** $10,000 + (4×$1,000) + (24×$300) = **$21,200**

Note how Growth becomes cheaper than Starter at scale because per-unit prices drop.

### Hours-Saved Calculator: Example Output
For a 100-employee company:
- Order processing: 5 people × 6 hrs/day = 30 hrs/day → 90% automation
- Customer support: 8 people × 8 hrs/day = 64 hrs/day → 70% automation  
- Reporting: 3 people × 4 hrs/day = 12 hrs/day → 80% automation
- HR processes: 2 people × 5 hrs/day = 10 hrs/day → 60% automation
- **Total:** 116 hrs/day → **~30,000 hrs/year = ~1.5B MNT savings**
