# AI Global — Brand Carousel Guidelines

## Overview

AI Global (aiglobal.mn, info@aiglobal.mn) — Mongolian education brand teaching AI skills. **Style: Italian minimal magazine** — light, airy, elegant. Two courses:
- **AI Vibe Coder™** — build an MVP in 3 weeks (M. Eland, starts June 15)
- **AI+ Agent™** — build AI agents (A. Munkh-Uchral, starts June 2)

Each course: 1,250,000 MNT, 3 weeks, high school + university students, group discount 10% off per friend. AI+ Agent™ includes AI CERTS internationally recognized certificate; median hiring salary $108k/yr.

### Content Type Labels (Top-Left, Mongolian)

Labels display inside a **gold (#D7AB46) rounded pill/chip badge** with white text, Manrope Bold ~24px.

### 4-Slide Carousel Structure

| Slide | Role | Content | Typography |
|-------|------|---------|------------|
| 1 | **Hook** | Big headline + visual | Headline 64px+ bold |
| 2 | **Explain** | 2-3 bullet points | Headline 44px + body 28-30px |
| 3 | **Deepen** | Stats, proof, gold numbers | Gold #D7AB46 numbers 56-72px |
| 4 | **CTA** | Call to action + course name | Gold CTA headline 50px |

### Image Placement Rule — Industry Updates Only

**"🌍 Салбарын мэдээ" carousels ONLY:** Include the actual news article image as a visual element. Placement: right side or bottom-right quadrant, rounded corners, clean frame with subtle shadow, ~30-40% of slide width. Text goes on left/top.

**All other carousel types (Educational, Product):** Text-only minimal design — no article images.

**Success Story (🏆 Амжилтын түүх):** Text-only by default. When a student/person photo is provided, use two-stage overlay: KIE GPT Image 2 generates the branded slide with a reserved photo frame, then Pillow composite overlays the actual photo. See `kie-content-maker` skill's `references/testimonial-photo-two-stage-overlay.md`.

### Design Specs

| Property | Value |
|----------|-------|
| Style | **Italian minimal magazine** (light, airy, sophisticated) |
| Format | 1:1 square (1080×1080) |
| Font | **Manrope** (headlines Bold, body Regular) |
| Background | Light cream **#FAFAF8 / #F5F3EF** with subtle texture (soft grain, marble, faint abstract shapes) |
| Text color | Dark charcoal **#1A1A1A** (not pure black) |
| Accent | Gold **#D7AB46** for badges, numbers, dividers, icons |
| Logo | Top-right, ~15% of slide width, proportional, padded |
| Contact | Bottom-left, clean text, no background bar: "📞 89097454  🌐 aiglobal.mn" in #1A1A1A Manrope 20-22px |
| Slide counter | ❌ **Do NOT include** (user explicitly rejected) |
| Voice | Professional, modern, educational |
| Language | Mongolian only |

### Reel Branding

Same visual rules applied to vertical (9:16) video:
- Logo top-right
- Phone + website bottom-left overlay
- Manrope font for text overlays
- Black/gold/white color scheme
