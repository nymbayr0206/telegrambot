# Enterprise AI Agent Transformation Guideline

## Usage (Хэрэглээ)

**Load this skill when:**
- Пүүс / байгууллагад AI агент transformation хийх зөвлөгөө өгөх
- Enterprise-д AI agent adoption стратеги боловсруулах
- Training / presentation бэлтгэх (phase бүрт what + why + benefits)
- Бүрэн action checklist гаргах, Google Docs/Slides руу хийх
- **Үнийн санал / pricing strategy боловсруулах** (freemium + 3-tier + per-skill/per-agent dynamic pricing)
- **Сар бүрийн кредит багц / monthly credit model боловсруулах** (API өртөг дээр суурилсан, 100K/390K/990K₮ багц, нэг үйлдлийн өртөг, бизнес үнэ цэнэ тооцоолол. DeepSeek Flash, KIE.ai GPT Image 2, Veo 3 Fast зэрэг API-уудын бодит өртөг дээр тулгуурлана — `references/operational-credit-pricing.md`-г үзнэ үү)
- **Харилцагчид хүний цаг хэмнэлтийн тооцоолуур үзүүлэх** (readiness assessment + time-savings calculator)
- Deep-dive хийх тодорхой эх сурвалж (Microsoft, Salesforce, BCG г.м)

**Writing convention:** Монгол-Англи хос хэлээр. Phase-ийг PHASE 0-6 гэж дугаарлана. Checkbox жагсаалт ашиглана.

## Framework Overview (Тойм)

A synthesized framework from 8+ leading sources:

### The 7-Phase Transformation Model

| Phase | Name | Core Question |
|-------|------|---------------|
| **0** | Readiness Assessment (Оношлогоо) | Where are we today? |
| **1** | Strategy & Planning (Стратеги) | Where are we going? |
| **2** | Governance & Foundation (Удирдлага) | What are the rules? |
| **3** | Data & Infrastructure (Өгөгдөл, Дэд бүтэц) | What do we need? |
| **4** | Pilot & Build (Туршилт) | Does it work? |
| **5** | Scale & Orchestrate (Өргөтгөл) | How do we amplify? |
| **6** | Continuous Optimization (Оновчлол) | How do we sustain? |
