# Mongolian Real Estate Content Creation

## Workflow

### 1. Project Research

Search across these Mongolian-specific sources (parallel search):

- **Facebook groups** — most active market. Search:
  - Group name + city (e.g., `ЭРДЭНЭТ ЗАР`, `Эрдэнэт үл хөдлөх`)
  - Project name in both English and Mongolian
  - Marketplace listings at `facebook.com/marketplace`
- **Unegui.mn** — `unegui.mn/new-buildings/` filtered by city
- **Barilga.mn** — `barilga.mn` for project details
- **RE/MAX Mongolia** — `remax.mn` for comparable pricing
- **Direct Facebook page** — project's official page often has pinned posts with full specs

Search queries should combine:
- Project name (English + Mongolian Cyrillic)
- City/location
- Keywords: `үнэ`, `давхар`, `талбай`, `ашиглалтанд орох`, `урьдчилгаа`

### 2. Data to Collect

For a complete buyer-facing script, gather:

| Data Point | Source |
|---|---|
| Location (district, landmark, smoke-free zone) | Facebook page, groups |
| Completion date | Marketplace / group posts |
| Block count (A, B, C, D…) | Group posts |
| Unit sizes (m²) and room count | Marketplace listings |
| Price per m² (₮) by payment terms | Marketplace listings |
| Down payment % and installment terms (e.g., 24-month interest-free leasing) | Posts |
| Key features (smart security, parking, children's safety, heating, windows) | Project page |
| Phone numbers (multiple agents) | Every post |
| Barter acceptance | Marketplace posts |

### 3. Script Structure — 1-Minute Short (Reels/Shorts/Stories)

**⏱ 0:00-0:05 — Hook** (strong opening, state name + city)
**⏱ 0:05-0:20 — Location** (district, landmark, smoke-free zone, why it matters)
**⏱ 0:20-0:35 — Project Specs** (blocks, completion date, unit sizes)
**⏱ 0:35-0:50 — Key Features** (security, parking, children, smart systems)
**⏱ 0:50-1:00 — CTA** (price, payment terms, contact number)

### 4. Buyer Psychology (Mongolian Market)

- **Smoke-free zone / АА бүс** is a top selling point — lead with it in Erdenet/UB suburban projects
- **24-month interest-free leasing** (хүүгүй хувь лизинг) is standard and expected
- **Barter** (хуучин байраа бартер) opens the market to upgrade buyers
- Mention **smart security** (ухаалаг харуул хамгаалалт) — differentiating factor
- **Children's safe environment** resonates with family buyers
- Price per m² + total visible price anchors work better than just m² alone

## Pitfalls

- Facebook content is rate-limited for web search — you may need browser interaction (not available via web_extract). Search results often show OCR'd text snippets; piece together multiple listings.
- Completion dates are aspirational — cross-reference multiple posts. Dates like "2026 оны 3-р улирал" vs "4-р улирал" vary by block.
- Phone numbers often differ between posts (developer vs. agents). List the most recent contact.
- Don't extract from `facebook.com/p/` or `facebook.com/profile.php` — these require login. Use group and marketplace posts instead.

## Verification

- Price data: cross-reference at least 2 independent Facebook posts
- Location: verify against city landmarks described in the post
- Ensure all unit sizes in m² are stated — Mongolian buyers compare by m²
