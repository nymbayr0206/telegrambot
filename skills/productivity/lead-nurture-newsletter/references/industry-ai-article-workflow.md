# Industry AI Article Workflow

Use this reference when preparing short Mongolian AI/technology articles for the user's website, newsletter, Telegram previews, or social posts.

## User-preferred shape

- Language: Mongolian by default.
- Source policy: browse/read public sources only; avoid login-gated sources unless the user explicitly provides access.
- Length options:
  - Short daily brief: 80–120 Mongolian words.
  - Use-case article: ~250 Mongolian words.
- Every article should include:
  - Title
  - Industry
  - Source link(s)
  - AI use case: how AI is being used
  - Change/result: what changed for the business/workflow
  - Mongolia application angle: how a local company could start
  - Image prompt or generated/selected image
  - Optional CTA for AgenticForce

## Article structure for ~250 words

```markdown
## <Mongolian title>

**Салбар:** <industry>
**Эх сурвалж:** <source name + URL>

<Article in Mongolian, ~250 words. Cover:>
1. What AI is being used for in the industry.
2. A concrete workflow/use case.
3. What changed: speed, cost, safety, quality, personalization, productivity, or risk control.
4. How Mongolian organizations can start with a practical workflow.

**Image prompt:** <photorealistic/professional prompt, Mongolian context if humans are shown>
**CTA:** Танай байгууллага AI workflow эхлүүлэхийг хүсвэл AgenticForce-тэй холбогдоорой.
```

## Pitfalls

- Do not write generic “AI is changing everything” content. Anchor each piece in a concrete workflow or industry use case.
- Keep source links visible so the user can trust and reuse the article.
- Avoid overly long academic summaries. The target is business-friendly Mongolian content.
- When creating images for this user's brand, prefer professional photorealistic output and Mongolian-looking people when humans are depicted.
