# Social Media

## Brand Asset Structure

Hermes dashboard manages social-content brand files from:

```text
skills/social-media/brands/<brand-name>/
├── logos/
├── fonts/
├── templates/
├── settings/
└── assets/
```

Use the dashboard tab `Брэнд assets` to view brands, create a brand, and upload files for logos, fonts, poster templates, settings, and reusable assets.

Agents creating social content should inspect the selected brand folder before producing posts, posters, captions, or campaign materials.
